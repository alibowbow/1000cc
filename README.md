# 천자문 · 千字文

천자문 1,000자의 순서와 훈음을 실제로 암기할 수 있도록 만든 무의존 정적 학습 웹앱입니다. Vanilla JavaScript ES Module, CSS, HTML만 사용하며 GitHub Pages와 오프라인 환경에서 동작합니다.

## 네 가지 학습 화면

- **전체 보기** — 100자 범위를 4자구 또는 8자 연으로 살펴보고 한자·독음·훈음·풀이를 검색합니다. 개별 한자 버튼을 누르면 화면 이동 없이 ‘하늘 천’처럼 훈음을 읽습니다. 뜻 가리기 중에는 같은 칸을 누를 때마다 그 칸의 뜻만 보이거나 다시 가려집니다. 최근 오답, 복습 예정, 숙련 상태 필터를 지원합니다.
- **구절 학습** — 두 개의 4자구를 나란히 익히고 글자·8자 연을 듣습니다. 선택 글자는 검증된 훈음과 부수·총획, 해당 글자가 실제로 쓰인 한자어와 국립국어원 사전 뜻을 보여 줍니다. 독음·뜻 가리기와 명시적인 정답 보기를 지원합니다.
- **연속 그리드** — 다음 글자를 순서대로 찾으면 정답 칸 하나만 새 글자로 교체됩니다. 4×4/5×5, 네 가지 난이도, 40·100·200·1,000자 세션, 힌트, 일시정지와 세션 복원을 지원합니다.
- **복습** — 오늘 복습, 최근 오답, 자주 틀리는 글자, 원하는 100자 범위에서 글자를 골라 연속 그리드로 다시 학습합니다.

## 학습 기록

글자별로 본 횟수, 정답·오답 수, 연속 정답, 0–5단계 숙련도, 마지막 학습 시각과 복습 예정일을 저장합니다. 복습 간격은 숙련도에 따라 당일·1일·3일·7일·30일입니다.

기존 cheonjamun-study-v1 기록은 최초 실행 때 cheonjamun-study-v2로 안전하게 이관됩니다. 기존 익힘 글자는 숙련도 2단계로, sequenceCursor는 연속 그리드 이어하기 위치로 이전됩니다. 설정에서 학습 기록을 JSON으로 내보내거나 불러오고 전체 초기화할 수 있습니다.

## 음성

Web Speech API에 한글 문자열만 전달합니다.

- ko-KR 음성을 우선 수집
- 사용 가능한 경우 이름에 Google이 포함된 한국어 음성을 우선 선택
- Google 음성이 없으면 설치된 한국어 음성 또는 브라우저 기본 음성으로 대체
- session token으로 취소된 재생의 늦은 콜백과 빠른 터치로 인한 음성 누적 방지
- 화면 이동, visibilitychange, pagehide에서 연속 재생 정리

Google 한국어 음성은 모든 브라우저에 존재하지 않습니다. 앱과 학습 기록은 오프라인에서도 동작하지만, 음성 재생은 운영체제나 브라우저에 설치된 음성 환경에 따라 오프라인에서 제한될 수 있습니다. Google Cloud API 키나 비공식 TTS URL은 사용하지 않습니다.

## 실행과 테스트

빌드 과정이나 런타임 의존성이 없습니다.

    npm run serve

브라우저에서 http://localhost:4173 을 엽니다.

    npm test

테스트는 1,000자 데이터·훈음 대응, 4자구 분리, 연속 그리드 슬롯 교체와 40/100/1,000자 완료, 세션 복원, v1 마이그레이션, 숙련도·복습 일정, JSON 검증, 한국어 음성 우선순위와 TTS session token을 검증합니다.

## 오프라인과 배포

sw.js가 HTML, CSS, JavaScript, 데이터, 아이콘과 manifest를 버전별로 캐시하고 이전 캐시를 정리합니다. 모든 경로는 저장소 하위 경로에서도 동작하는 상대 경로입니다. .github/workflows/pages.yml은 main의 정적 파일을 GitHub Pages에 배포합니다.
