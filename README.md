# 천자문 · 千字文

천자문 1,000자를 100자 단위 그리드로 살펴보고, 브라우저의 한국어 음성 합성으로 들으며 익히는 무의존 정적 웹앱입니다.

## 주요 기능

- 1,000자 전체를 100자씩 나눈 반응형 글자판
- 글자 선택 시 한글 독음 재생과 해당 8자 연의 풀이 표시
- 순서대로 글자를 눌러 진행하는 순서 익히기 모드
- 선택한 8자 연부터 이어 읽는 소리 듣기 모드
- Chrome의 Google 한국어 음성을 우선하는 Web Speech API 연동
- 음·풀이 가리기, 읽기 속도와 목소리 선택
- 익힘 상태와 순서 학습 위치의 로컬 저장
- 키보드 방향키 탐색 및 축소 모션 설정 지원

## 실행

빌드 과정이나 외부 의존성이 없습니다.

    npm run serve

브라우저에서 http://localhost:4173 을 엽니다.

## 테스트

    npm test

## 자료

원문, 한국어 독음과 풀이는 [한국어 위키문헌 「번역:천자문」](https://ko.wikisource.org/wiki/%EB%B2%88%EC%97%AD:%EC%B2%9C%EC%9E%90%EB%AC%B8)의 공개 자료를 기준으로 정리했습니다.
