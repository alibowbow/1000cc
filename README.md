# 천자문 · 千字文

하루 5분씩 한 연(8자)을 익혀 125일에 천자문을 완주하도록 만든 로컬 우선 정적 학습 웹앱입니다. Vanilla JavaScript ES Module, CSS, HTML만 사용하며 GitHub Pages와 오프라인 환경에서 동작합니다. 회원가입이나 서버 API는 필요하지 않습니다.

## 오늘의 5분 학습

앱을 열면 메뉴 목록 대신 아직 끝내지 않은 연에서 무작위로 고른 **오늘의 8자**가 바로 열립니다. 같은 날에는 새로고침해도 같은 연이 유지되고, 원하면 다른 8자를 다시 뽑을 수 있습니다.

1. 오늘의 8자 훈음·전체 뜻 익히기
2. 각 연에 맞춘 그림과 네 개 단서로 8자 떠올리기
3. 한자→독음, 한자→뜻, 뜻→한자의 세 방향 회상
4. 순서대로 다음 글자를 찾는 8자 순서 게임
5. 현대 한자어를 확인하고 소요 시간·정답률·진도 저장

학습 중인 단계와 보드 상태는 새로고침 뒤에도 이어집니다. 일일 완료일과 연속 학습일을 기록하며, 125개 연마다 서로 다른 기억 장면과 직접 선별한 현대 어휘를 제공합니다.

## 보조 학습 화면

- **전체 보기** — 100자 범위를 4자구 또는 8자 연으로 살펴보고 한자·독음·훈음·풀이를 검색합니다. 개별 한자 버튼을 누르면 화면 이동 없이 ‘하늘 천’처럼 훈음을 읽습니다. 뜻 가리기 중에는 같은 칸을 누를 때마다 그 칸의 뜻만 보이거나 다시 가려집니다. 최근 오답, 복습 예정, 숙련 상태 필터를 지원합니다.
- **구절 학습** — 두 개의 4자구를 크게 익히고, 각 연의 실제 장면을 그린 기억 그림에서 네 단서를 눌러 두 글자씩 회상합니다. 선택 글자는 훈음·부수·총획·현대 한자어와 사전 뜻을 보여 줍니다.
- **한자 순서 게임** — 다음 글자를 순서대로 찾으면 정답 칸 하나만 새 글자로 교체됩니다. 4×4/5×5, 네 가지 난이도, 40·100·200·1,000자 세션, 힌트, 일시정지와 세션 복원을 지원합니다.
- **복습** — 학습 메뉴 아래의 작은 보조 기능입니다. 최근 오답·자주 틀리는 글자·원하는 100자 범위만 골라 순서 게임으로 다시 볼 수 있습니다.

`?challenge=1`부터 `?challenge=125`까지의 URL은 학습 기록이나 회원가입 없이 바로 푸는 **오늘의 8자 도전**을 엽니다. 오늘 화면의 공유 버튼으로 해당 링크를 보낼 수 있습니다.

## 학습 기록

글자별로 독음·뜻·역방향·순서·듣기 기록을 각각 저장하고, 본 횟수·정답·오답·연속 정답·마지막 학습·복습 예정일을 함께 관리합니다. 한날에 여러 번 맞힌 것만으로 완전 숙련이 되지 않으며, 서로 다른 날짜에 반복해서 맞혀야 영역별 숙련도가 5단계까지 오릅니다. 복습 간격은 숙련도에 따라 당일·1일·3일·7일·30일입니다.

기존 cheonjamun-study-v1 기록은 최초 실행 때 cheonjamun-study-v2로 안전하게 이관됩니다. 기존 익힘 글자는 숙련도 2단계로, sequenceCursor는 한자 순서 게임 이어하기 위치로 이전됩니다. 설정에서 학습 기록을 JSON으로 내보내거나 불러오고 전체 초기화할 수 있습니다.

## 음성

Web Speech API에 한글 문자열만 전달합니다.

- ko-KR 음성을 우선 수집
- 사용 가능한 경우 이름에 Google이 포함된 한국어 음성을 우선 선택
- Google 음성이 없으면 설치된 한국어 음성 또는 브라우저 기본 음성으로 대체
- session token으로 취소된 재생의 늦은 콜백과 빠른 터치로 인한 음성 누적 방지
- 화면 이동, visibilitychange, pagehide에서 연속 재생 정리

Google 한국어 음성은 모든 브라우저에 존재하지 않습니다. 앱과 학습 기록은 오프라인에서도 동작하지만, 음성 재생은 운영체제나 브라우저에 설치된 음성 환경에 따라 오프라인에서 제한될 수 있습니다. Google Cloud API 키나 비공식 TTS URL은 사용하지 않습니다.

## 실행과 테스트

빌드 과정이나 런타임 의존성이 없습니다.

    npm run serve

브라우저에서 http://localhost:4173 을 엽니다.

    npm test

테스트는 125일 과정·기억 장면·현대 어휘 선택, 1,000자 데이터·훈음 대응, 한자어 독음 정합성, 한자 순서 게임 슬롯 교체와 40/100/1,000자 완료, 일일 세션 복원, v1 마이그레이션, 영역별 숙련도·복습 일정, 공유 링크, JSON 검증, 한국어 음성 우선순위와 TTS session token을 검증합니다.

## 오프라인과 배포

sw.js가 HTML, CSS, JavaScript, 125개 기억 그림, 125일 콘텐츠, 데이터, 아이콘과 manifest를 버전별로 캐시하고 이전 캐시를 정리합니다. 한 번 온라인에서 연 뒤에는 전체 보기·오늘의 학습·한자 순서 게임·복습 기록을 오프라인에서도 사용할 수 있습니다. 모든 경로는 저장소 하위 경로에서도 동작하는 상대 경로입니다. .github/workflows/pages.yml은 main에서 테스트가 통과한 정적 파일을 GitHub Pages에 배포합니다.
