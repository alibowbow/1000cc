# 천자문 · 千字文

천자문을 한 글자씩 이어 보거나 8자 연으로 읽고, 한자 맞추기 게임으로 확인할 수 있는 로컬 우선 정적 웹앱입니다. Vanilla JavaScript ES Module, CSS, HTML만 사용하며 GitHub Pages와 오프라인 환경에서 동작합니다. 회원가입이나 서버 API는 필요하지 않습니다.

## 오늘의 8자

앱을 열면 125개 연에서 무작위로 고른 **오늘의 8자**가 바로 열립니다. 같은 날에는 새로고침해도 같은 연이 유지되고, 원하면 `랜덤 8자`로 다시 뽑을 수 있습니다. 각 연의 기억 그림은 원래 3:4 프레임 전체를 보여 줍니다.

## 세 가지 메뉴

- **1자 보기** — 1,000자를 끊김 없는 한 글자 그리드로 살펴보고 한자·독음·훈음·풀이를 검색합니다. 글자를 누르면 ‘하늘 천’처럼 훈음을 읽고, 뜻을 가리거나 다시 확인할 수 있습니다.
- **8자 보기** — 두 개의 4자구를 크게 읽고, 바로 아래에서 선택 글자의 훈음·부수·총획을 확인합니다. 기억 그림의 네 단서는 아래에서 두 글자씩 확인할 수 있습니다.
- **한자 맞추기** — 뜻과 독음을 보고 네 개의 후보 중 맞는 한자를 고릅니다. 현재 보고 있는 8자 또는 무작위 8자로 바로 시작할 수 있고, 틀린 글자만 다시 풀 수 있습니다.

`?challenge=1`부터 `?challenge=125`까지의 URL은 학습 기록이나 회원가입 없이 바로 푸는 **오늘의 8자 도전**을 엽니다. 오늘 화면의 공유 버튼으로 해당 링크를 보낼 수 있습니다.

마지막 게임 위치와 설정은 브라우저에 저장되어 새로고침 뒤에도 이어집니다. 예전 학습·복습 화면을 저장한 사용자는 오늘 화면으로 자동 전환되며 기존 데이터 자체는 손상시키지 않습니다.

## 음성

Web Speech API에 한글 문자열만 전달합니다.

- ko-KR 음성을 우선 수집
- 사용 가능한 경우 이름에 Google이 포함된 한국어 음성을 우선 선택
- Google 음성이 없으면 설치된 한국어 음성 또는 브라우저 기본 음성으로 대체
- 재생 직전에 음성 목록을 다시 확인하고 일시 정지된 음성 엔진을 자동 재개
- 선택한 음성이 실패하면 다른 한국어 음성으로 한 번 자동 재시도
- session token으로 취소된 재생의 늦은 콜백과 빠른 터치로 인한 음성 누적 방지
- 화면 이동, visibilitychange, pagehide에서 연속 재생 정리

Google 한국어 음성은 모든 브라우저에 존재하지 않습니다. 앱과 게임은 오프라인에서도 동작하지만, 음성 재생은 운영체제나 브라우저에 설치된 음성 환경에 따라 오프라인에서 제한될 수 있습니다. Google Cloud API 키나 비공식 TTS URL은 사용하지 않습니다.

## 실행과 테스트

빌드 과정이나 런타임 의존성이 없습니다.

    npm run serve

브라우저에서 http://localhost:4173 을 엽니다.

    npm test

테스트는 오늘의 무작위 8자·기억 장면·현대 어휘, 1,000자 데이터·훈음 대응, 한자 맞추기 후보와 세션 복원, 저장 데이터 마이그레이션, 공유 링크, 한국어 음성 우선순위와 TTS session token을 검증합니다.

## 오프라인과 배포

sw.js가 HTML, CSS, JavaScript, 125개 기억 그림, 데이터, 아이콘과 manifest를 버전별로 캐시하고 이전 캐시를 정리합니다. 한 번 온라인에서 연 뒤에는 1자 보기·8자 보기·한자 맞추기를 오프라인에서도 사용할 수 있습니다. 모든 경로는 저장소 하위 경로에서도 동작하는 상대 경로입니다. .github/workflows/pages.yml은 main에서 테스트가 통과한 정적 파일을 GitHub Pages에 배포합니다.
